點擊「進入遊戲」載入外部遊戲，不需登入本站。另開遊戲 ↗
01

帶著隊伍出發

點地面移動，或在電腦使用方向鍵。操作前先點一下遊戲畫面，讓鍵盤焦點進入遊戲。

02

靠近光圈，探索景點

跟著街道走訪景點，靠近光圈即可進入。使用遊戲裡的村落地圖幫助定位。

03

把記憶收進手帳

在遊戲裡打開「記憶手帳」，看看你收集了哪些發現。完成後也能回到影片任務版留下筆記。

關於這個遊戲

遊戲已獨立發布至 GitHub Pages，本頁直接嵌入正式遊戲，不再使用臨時通道。遊戲進度不會自動計入 H5P 或本站印章；NPC 故事為創作。若內嵌畫面載入不順，可點「另開遊戲」使用完整頁面。
